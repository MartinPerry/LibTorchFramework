
LibTorch C++ Wrapper / Framework

Most of the modules are rewrites from Python implementations uscing Codex or ChatGPT 5
and manually checked and tested.

#--------------------------------------------
Available models in zoo:

ResNet (writen based on tutorials)
UNet (writen based on tutorials)
U2Net (https://github.com/xuebinqin/u-2-net)
SDVAE (unknown source)
LLama (just for fun - entire code was generated by Codex)
SimVPv2 (https://github.com/Lupin1998/SimVPv2)
exPreCast (https://github.com/tony890048/exPreCast/tree/main)
